Windows App (AVD) Shortcuts Cheat Sheet

All customized Mac-to-Windows shortcuts active while Windows App is focused

📋 Clipboard & Text
Paste from Mac to Windows (AVD) Types Mac clipboard text into remote Windows session
⌥ Opt+⌘ Cmd+V
Windows Clipboard History Invokes native Windows Win + V history palette
⇧ Shift+⌘ Cmd+V
Standard Edit Commands Remapped automatically to Windows Ctrl+C, Ctrl+V, etc.
⌘ Cmd+C / V / Z / A
💡 Copying WA → macOS: Best done via CleanShot X OCR (⇧⌘0) to instantly grab any text on screen directly into macOS!
🖥️ Windows Navigation & Snapping
Switch Windows Apps Invokes native Windows Alt + Tab switcher
⌘ Cmd+Tab
Snap Windows (Left / Right / Max / Min) Windows key + Arrow snapping inside AVD
⌘ Cmd+← / → / ↑ / ↓
Move Window to Another Monitor Shift + Win + Arrow across multi-monitors
⇧ Shift+⌘ Cmd+Arrows
📸 Screen Capture
Windows Snipping Tool (Native) Win+Shift+S: Autosaves to OneDrive & clipboard without extra clicks
⇧ Shift+⌘ Cmd+S
CleanShot X: Area & Annotate Opens capture with CleanShot markup editor on Mac
⇧ Shift+⌘ Cmd+5
CleanShot X: Area to Clipboard Immediately copies area capture to Mac clipboard
⇧ Shift+⌘ Cmd+6
CleanShot X: Area & Save Saves screenshot directly to Mac Xshots folder
⇧ Shift+⌘ Cmd+7
CleanShot X: Text OCR Copies extracted on-screen text to Mac clipboard
⇧ Shift+⌘ Cmd+0
🚀 Mac Global Shortcuts
Alfred Search / Launcher Passes through to macOS Alfred overlay
⌘ Cmd+Space
Todoist Quick Add Task Brings up Todoist quick task entry dialog
⌃ Ctrl+Space
Pause / Play Media (macOS) Toggles playback on macOS media players
⌃ Ctrl+⌥ Opt+⌘ Cmd+=
Toggle This Shortcuts Cheat Sheet Instant overlay of all active Windows App mappings
⌘ Cmd+?
Tip: Press Esc or ⌘ Cmd + ? anytime to dismiss this cheat sheet.
